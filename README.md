# hellodaryy-vk-feed

Витрина для раздела «Товары» сообщества ВКонтакте: YML-фид и обложки товаров.

- `feed.yml` — каталог для импорта. В ВК: «Товары → Добавить товар → ссылка на файл»,
  с галочкой «Автоматически создать подборки товаров по категориям».
- `images/` — обложки, имя файла соответствует id поста в канале.

Репозиторий публичный, потому что ВК ходит за файлами анонимно. Содержимое
собирается автоматически из приватного `aiogram_catalog_bot`, руками здесь
ничего не правится — правки не переживут следующую сборку.
